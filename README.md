# HSK 3.0 語彙学習

日本語話者向けの HSK 3.0 語彙学習ページです。HSK 1〜6 と、原資料で一つにまとめられた HSK 7〜9 の計 11,000 件を収録しています。ピンイン、品詞、日本語の意味、元の英語の意味を確認できます。

級ごとの単語一覧、漢字・ピンイン・日本語の検索、学習済みの記録、20語ごとの学習、三種類の練習、復習、学習記録のバックアップに対応しています。学習記録は同じブラウザに保存され、従来の HSK サイトの記録とは別です。

元の HSK サイトに同じ漢字とピンインの音声がある 4,702 件は、元サイトの録音を再生します。残りの音声は準備中です。まとめて再生する場合は音声のある単語のみ再生します。元サイトへの接続が必要です。

`spreadsheets/` に日本語の意味を追加した Excel ファイルがあります。英語の意味など、元の情報も残しています。HSK 7〜9 の級欄は、元ファイルで日付になっていた値を「7–9」に整理しました。日訳は引き続き校正してください。

ローカルでは `python3 -m http.server 8000` を実行し、`http://localhost:8000/` を開いてください。テストは Node.js と Chromium を使い、`npm ci` の後に `npm test` で実行できます。必要に応じて `CHROMIUM_PATH` で Chromium の実行ファイルを指定します。
