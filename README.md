# HSK 3.0 学習（単語・漢字・文法）

日本語話者向けの HSK 3.0 学習ページです。「新版HSK考試大綱（詞彙・漢字・語法）」（2025年11月発布、2026年7月実施）の三つの部分をもとに作っています。

- **単語**：HSK 1〜6 と、大綱で一つにまとめられた HSK 7〜9 の計 11,000 語。ピンイン、品詞、日本語の意味、英語の意味を確認できます。**全 11,000 語に音声があります。** 級ごとの一覧、検索、学習済みの記録、20語ごとの学習、復習、学習記録のバックアップに対応しています。
- **練習**：級ごとにランダムに出題します。「意味を選ぶ」「中国語を選ぶ」「ピンインを選ぶ」「音声で選ぶ」（録音を聞いて単語を選ぶ）の4種類で、問題数は 10・20・30・全部から選べます。
- **漢字**：各級の認読字（計 3,088 字）と書写字（計 1,200 字）。字をタップすると、その字を使う単語を音声つきで確認でき、「読める字／書ける字として覚えた」を記録できます。
- **文法**：各級の語法項目（計 593 項目）。大綱の用語に日本語の参考訳を付けています。品詞の項目に挙がっている語は、タップで音声を聞けます。各項目には、やさしい日本語の解説と例文（日本語訳つき）があります（このサイトで作成。`data/grammar-notes.js`）。「解説と例文」のチェックを外すと、項目だけの一覧になります。「練習する」では、例文の（　）に入る語を選ぶ問題（計 116 問）を級ごとにランダムに出題し、答えた後に日本語訳と解説を表示します。例文は大綱にはなく、このサイトのために作成したものです（`data/grammar-practice.js`）。

学習記録は同じブラウザに保存されます。従来の HSK サイトの記録とは別です。

## 使い方

サーバーは不要です。フォルダごと保存して `index.html` をダブルクリックしても、GitHub Pages に置いても動きます。ローカルサーバーで確認する場合は `python3 -m http.server 8000` を実行し、`http://localhost:8000/` を開いてください。

## 音声

`audio/` に 10,192 個の MP3 があります（合成音声、リリース `20261117-approved-voice-v1`）。11,000 語すべてに対応し、読みが同じ語は同じ録音を使います。単独では発音しにくい字（吧・了 など）は例の語で録音してあり、画面に「音声の例：好吧」のように表示します。語と録音の対応は `data/audio-index.csv` と `data/audio-release.json` にあります。

## データ

| ファイル | 内容 |
| --- | --- |
| `data/vocab.js` | 単語 11,000 語。語・ピンイン・級・品詞は大綱 PDF から、日本語・英語の意味は従来のデータから |
| `data/chars.js` | 認読字・書写字の一覧（大綱の順） |
| `data/grammar.js` | 語法大綱の各項目 |
| `data/grammar-ja.js` | 語法用語の日本語参考訳 |
| `data/grammar-notes.js` | 文法項目ごとの解説と例文 |
| `data/grammar-practice.js` | 文法練習の問題（例文・選択肢・答え・訳・解説） |
| `spreadsheets/` | 日本語の意味を追加した Excel（英語の意味など元の情報も残しています。日訳は引き続き校正してください） |
| `docs/` | 大綱 PDF 原本と維持管理の手引き |

大綱 PDF と異なる表記にした語（ピンイン 5 語）など、確認していただきたい点は `docs/维护指南.md` にまとめています。

## 検査とテスト

- データの検査：`node tools/check.js`、またはブラウザで `check.html` を開きます。
- テスト：Node.js と Chromium を使い、`npm ci` の後に `npm test` で実行できます。必要に応じて `CHROMIUM_PATH` で Chromium の実行ファイルを指定します。
