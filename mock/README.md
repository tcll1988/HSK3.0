## 主な機能

- **全画面日本語UI**（中国語本文・選択肢・リスニング原文は `lang="zh-CN"` で表示、ピンイン ON/OFF 切替対応）
- **練習モード（1問ずつ定着・正解必須ステップ方式）**
  - 原題順／ランダム順、全問題／セクション別／パート別の絞り込みに対応
  - 誤答時は即座に正解・リスニング原文スクリプト・日本語訳・「なぜこれが正解？」詳細解説・日本人学習者向けポイントを表示し、正しく選び直すまで次へ進めない設計
- **試験モード（模擬試験）**
  - 本番どおり（公式通し音声＋再生位置の自動追従）またはランダム順で解答
  - 試験タイマー・解答シート・見直しフラグ・提出後の成績レポート＆「間違いのみ」復習モード
- **記述・作文・翻訳・口語サポート**
  - リアルタイム文字数カウンター、マイク録音＆再生（`MediaRecorder`）、準備／発話タイマー、模範解答（中国語＋日本語訳）、自己採点チェックリストを搭載
- **URLハッシュ直リンク対応**：`mock/index.html#hsk1` 〜 `mock/index.html#oral6` で特定の級を直接開けます

## 開発・再ビルド方法

```bash
cd mock/source
npm install
npm run dev    # ローカル開発（http://localhost:5175）
npm run build  # mock/ 直下へ静的ビルドを出力
```
