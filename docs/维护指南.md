# HSK 3.0 学习网站 维护指南

本指南写给维护网站的老师。网站本身（学生看到的界面）是日语；数据来自《新版HSK考试大纲（词汇、汉字、语法）（12.25）》PDF（2025-11 发布，2026-07 实施）和本库 `audio/` 里的录音。

## 一、网站有什么

| 部分 | 内容 | 数据来源 |
| --- | --- | --- |
| 単語（词汇） | 11,000 词，按 1–6 级和 7–9 级分开；拼音、词性、日语和英语释义；全部有录音。可搜索、标记“学习済み”、20 词一组学习、复习、导出/导入学习记录 | PDF 词汇大纲（第 1–276 页）＋原有的日语/英语释义＋`audio/` |
| 練習（单词练习） | 从本级随机抽题，四种题型：选意思、选中文、选拼音、**听录音选单词**。题数可选 10 / 20 / 30 / 全部（本级所有单词） | 同上 |
| 漢字（汉字） | 各级认读字共 3,088 字、书写字共 1,200 字（一级和二级的书写字在大纲里是一张表）。点字可以看含这个字的词并听录音，可以标记“读得出/写得出” | PDF 汉字大纲（第 277–306 页） |
| 文法（语法） | 「項目を見る」：各级语法项目共 593 行，按“类别 → 类别名称 → 细目”分组，术语旁边有日语参考译名；“词类”里列出的词可以点击听录音。**每一行下面有简单易懂的日语讲解和例句**（共 593 条讲解、859 个例句，带日语翻译），取消勾选「解説と例文」可以隐藏，搜索也能搜到讲解里的日语。「練習する」：例句选词填空，每级随机抽题（10 题或全部），答后显示日语翻译、解说和对应的大纲项目 | 项目：PDF 语法大纲（第 307–328 页）；**讲解、例句和练习题：为本网站编写，需要老师审核** |

网站不需要服务器：放在 GitHub Pages 上可以用，下载到电脑后直接双击 `index.html` 也可以用（录音也能播放）。

## 三、发布和离线使用

**开启 GitHub Pages（只需一次）**

1. 打开 GitHub 上的仓库 `tcll1988/HSK3.0`，点 **Settings → Pages**。
2. “Build and deployment” 的 Source 选 **Deploy from a branch**，Branch 选 **main**、文件夹选 **/(root)**，点 **Save**。
3. 等一两分钟，网址是 `https://tcll1988.github.io/HSK3.0/`。之后每次把修改推送到 main，网站会自动更新。

仓库根目录的空文件 `.nojekyll` 让 GitHub Pages 直接发布文件、不经过 Jekyll 处理（录音文件多，这样部署更快），请不要删除。

**离线使用**：在仓库页面点 **Code → Download ZIP**，解压后双击 `index.html`。整个文件夹约 245 MB（大部分是录音），请保持文件夹结构不变。

## 四、修改内容

所有数据文件都是 UTF-8 文本，用 VS Code 等编辑器打开即可（不要用 Word）。改完后运行检查（见第六节）。

### 1. 词汇 `data/vocab.js`

每行一条，例如：

```
{"id":7,"hanzi":"半","pinyin":"bàn","level":1,"levelNote":"1（4）","pos":"数、（副）","gloss":"半分、２分の１","english":"half","audio":"audio/07/entry-7.mp3","page":2},
```

| 字段 | 说明 |
| --- | --- |
| `id` | 大纲序号（1–11000），学习记录靠它识别，**不要改** |
| `hanzi` / `pinyin` | 词语和拼音。`本1`、`本2` 这样的数字是大纲区分同形词的编号 |
| `level` | 1–6，7 表示 7–9 级 |
| `levelNote` | 大纲里带括号的等级，如 `1（4）`：括号里的级别对应词性里括号中的用法（半：数词 1 级，副词 4 级）。没有括号就不写 |
| `pos` | 大纲原文的词性（中文简称）。短语、成语在大纲里没有词性，写 `""` |
| `gloss` / `english` | 日语释义 / 英语释义（学生看到的就是这里） |
| `audio` | 录音文件路径 |
| `audioText` | 录音里实际读的内容和词不同时填写（如 吧 → `好吧`），页面显示“音声の例：好吧” |
| `audioReading` | 有两个读音、录音只读其中一个时填写（谁 → `shéi`） |
| `page` | 大纲 PDF 的页码 |
| `pdfPinyin` | 拼音没有采用 PDF 写法时，记录 PDF 原文（见第九节） |

### 2. 汉字 `data/chars.js`

每个级别一串字，顺序就是大纲的编号顺序（第 1 个字就是 No.1）。改字时保持顺序；`pages` 是大纲页码。

### 3. 语法 `data/grammar.js` 和 `data/grammar-ja.js`

`grammar.js` 每行是 PDF 表格里的一个“语法内容”格子：`id`（编号，讲解靠它对应到这一行，见第 5 条）、`level`（1–6 或 `"7-9"`）、`page`、`cat`（类别）、`name`（类别名称）、`item`（细目）、`text`（语法内容，`\n` 表示原文换行）。合并单元格在每一行里都重复写出。

日语参考译名在 `grammar-ja.js`，左边是大纲用语（去掉末尾编号，如“结果补语”），右边是日语。想换成课堂上用的说法，只改右边即可；删掉某一行，页面就只显示中文。

### 4. 语法练习 `data/grammar-practice.js`

**这些例句不是 PDF 里的，是为本网站编写的，请老师审核后再让学生使用。** 每行一题，例如：

```
{"id":"g3-01","level":"3","cat":"句子的类型","name":"特殊句型","item":"“把”字句1","pattern":"（3）主语+把+宾语+动词+结果补语/趋向补语/状态补语","q":"我（　）作业做完了。","choices":["把","被","比","对"],"answer":"把","ja":"私は宿題をやり終えた。","note":"「把」構文「主語＋把＋目的語＋動詞＋結果補語」で、目的語をどう処置したかを表します。"},
```

| 字段 | 说明 |
| --- | --- |
| `id` | 题号，如 `g3-01`。学习记录靠它识别，**已有的题号不要改**；新题用新的号 |
| `level` | `"1"`–`"6"` 或 `"7-9"` |
| `cat` / `name` / `item` | 对应的语法项目，必须和 `data/grammar.js` 里该级某一行的类别 / 类别名称 / 细目一字不差（空的就写 `""`） |
| `pattern` | 那一行的“语法内容”原文，答题后显示 |
| `q` | 题目，填空处写成全角括号加全角空格「（　）」，只能有一个 |
| `choices` | 4 个选项（页面上的顺序每次随机，所以写的顺序无所谓） |
| `answer` | 正确答案，必须是 `choices` 里的一个 |
| `ja` / `note` | 日语翻译 / 解说，答题后显示 |

编写和修改时请特别注意：**4 个选项里只能有一个是对的**。例如“我（　）作业做完了”不能用“给”做干扰项，因为北方口语里“我给作业做完了”也能说。改了答案后，学生已经做过的题会按新答案重新判对错。改完请运行检查工具（见第六节），它会检查填空处、选项、答案和对应的语法项目。

### 5. 语法讲解和例句 `data/grammar-notes.js`

**讲解和例句也不是 PDF 里的，是为本网站编写的，请老师审核。** 每行对应 `grammar.js` 的一行，例如：

```
{"id":"r3-071","text":"（2）主语+被+动词+其他成分","ja":"動作をした人がわからないときや言う必要がないときは、「被」の後ろに直接動詞を置きます。","ex":[["我的蛋糕被吃了。","私のケーキが食べられてしまった。"]]},
```

| 字段 | 说明 |
| --- | --- |
| `id` | 对应 `grammar.js` 那一行的 `id`：`r` ＋ 级别（7–9 级写 `79`）＋ 该级里的行号，如 `r1-001`、`r79-134` |
| `text` | 那一行的“语法内容”原文（核对用，必须和 `grammar.js` 一字不差） |
| `ja` | 日语讲解（学生看到的说明） |
| `ex` | 例句，`[["中文", "日语翻译"], ...]`，1–3 个 |

- 改讲解或例句：只改 `ja` 和 `ex` 里的文字即可。中文例句里的引号请用中文引号“”，不要用英文的 `"`（否则要写成 `\"`）。
- 学生在“学習設定”里取消「日本語訳を表示」时，例句的日语翻译也会隐藏（讲解不隐藏）。
- **`text` 和 `grammar.js` 对不上时，网站不显示这条讲解**。这是为了防止讲解挂错地方：`id` 是按行号编的，如果重新生成 `grammar.js` 时中间多了一行，后面的编号都会往后移。检查工具会列出对不上的条目（“需要确认”），按新的编号把 `id` 和 `text` 改过来即可。
- 想让某一行不显示讲解，删掉这一行就行（检查工具会提示“还没有讲解”）。

### 6. 录音

- **替换录音**：用同名文件覆盖 `audio/` 里的 MP3（路径见 `data/audio-index.csv`）。读音相同的词共用一个文件（例如“半”和读 bàn 的其他词），替换一个文件会影响共用它的所有词，表里可以查到。
- **替换后**：把 `js/hsk.js` 里的 `AUDIO_VERSION` 改成新的值（例如 `"20261201-voice-v2"`），学生的浏览器才会重新下载，而不是继续播放缓存里的旧录音。
- `node tools/check.js` 会提示“N 个录音和 data/audio-release.json 记录的不同”，有意替换时这是正常的。
- 如果录音读的不是词本身（例词），在 `vocab.js` 的这一条加上或修改 `audioText`。

### 7. 页面上的日语文字

界面文字写在 `js/app.js`（単語・練習・设置）和 `js/syllabus-views.js`（漢字・文法・文法練習）里，用编辑器搜索要改的日语句子直接替换即可。

### 8. 关于“听录音选单词”

题目只从录音读的就是这个词本身的单词里出（`audioText` 为空的词）；用例词录音的 59 个词（如 吧→好吧）不出题。干扰项会排除和正确答案拼音相同、或共用同一个录音的词（如 半/办 都读 bàn），所以听得出区别。录音在学生点击后自动播放一次（浏览器不允许页面一打开就出声），之后可以按播放键重听。

## 五、学习记录怎么保存

- 学习记录保存在**学生自己的浏览器**里（localStorage），不上传到任何地方。换浏览器、换设备、清除网站数据都会看不到原来的记录。
- 键名：`hsk3-study-progress-v1`（级别、学习済み、复习日程、单词练习进度、汉字的“覚えた”、语法练习进度、是否显示语法讲解）和 `hsk3-study-preferences-v1`（速度、字号、单词练习的题数、显示拼音/日语等设置）。
- 语法练习只保存“题号 → 学生选的字”，对错每次按 `data/grammar-practice.js` 的当前答案重新判定。
- 换设备时：在“学習設定 → 学習記録のバックアップ”里点“記録を書き出す”，得到一个 JSON 文件；在新设备上用“記録ファイルを選ぶ”读入。
- 这次更新没有改变键名和词的序号，以前在本网站学习的记录会保留。旧 HSK 网站（tcll1988.github.io/HSK）的记录是分开的。

## 六、检查工具

改完数据后请运行检查：

- **浏览器版**：双击 `check.html`。显示“错误”“需要确认”和统计；下面的“开始检查录音”会逐个加载录音（约一万个，需要几分钟）。
- **Node 版**：在仓库文件夹运行 `node tools/check.js`（或 `npm run check`）。除了同样的规则，还检查录音文件是否存在、是否为空、是否真的是 MP3、`audio/` 里有没有没用到的文件、内容相同但词和读音都对不上的录音（疑似放错）、`index.html` 引用的文件是否都在。

“错误”必须修正；“需要确认”请老师判断；“信息”只是统计。当前结果：错误 0、需要确认 0。

## 八、从 PDF 重新生成数据

大纲 PDF 更新时可以重新生成（需要 Python 3 和 `pip install pdfplumber`）：

```
python3 tools/syllabus/extract.py docs/HSK3.0-syllabus-vocabulary-characters-grammar-12.25.pdf /tmp/hsk-syllabus
python3 tools/syllabus/build.py /tmp/hsk-syllabus
```

`build.py` 会重写 `data/vocab.js`、`data/chars.js`、`data/grammar.js`：词语、拼音、级别、词性从 PDF 来，日语和英语释义保留现在 `vocab.js` 里的内容，录音从 `data/audio-index.csv` 来。**手工改过的拼音会被 PDF 覆盖**，要保留的请加进 `build.py` 开头的 `KEEP_PINYIN`。脚本处理了 PDF 的水印、跨页合并单元格和上标编号（了¹、了²），具体做法写在 `extract.py` 开头。`grammar.js` 的 `id` 按每级的行号重新编写；如果 PDF 的语法表增删了行，请运行检查工具，按提示调整 `data/grammar-notes.js`（见第四节第 5 条）。

## 十一、没有做的验证

- 没有逐个试听 10,192 个录音。只检查了文件存在、格式、校验值，并在浏览器里实际播放了几个。听力题能不能听出区别，是按拼音和录音文件判断的，没有逐题试听。

- 只在 Chromium 内核（Playwright）里测试过，**Safari 和 Firefox 没有实测**。汉字详情使用浏览器自带的对话框（`<dialog>`），需要 Safari 15.4 以上。
- 汉字表和语法表是用程序从 PDF 抽取后核对的（方法见第九节），PDF 里没有汉字的读音，所以汉字页面不单独标读音，而是列出含这个字的词。
