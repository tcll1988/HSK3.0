# HSK 3.0 样卷演习（模擬試験）维护指南

本指南写给维护网站的老师。学生看到的界面是日语；本指南用中文。

演习页面在 `exam/` 文件夹，做法参照 HSKQ 库的 `chatgpt` 版：显示原卷页面图片，在图片上标出当前题目的位置；每题有录音片段、答案、听力原文和日语解说；有练习模式和考试模式，按题型显示成绩，学习记录保存在学生自己的浏览器里。

- 入口：`exam/index.html`（单词网站首页的「模擬試験」按钮会打开当前级别的样卷）
- 发布后网址：`https://tcll1988.github.io/HSK3.0/exam/`
- 数据来源：`HSK3.0_新版样卷/` 里的官方样卷 PDF、答案 PDF 和录音（来源说明见 `HSK3.0_新版样卷/说明.txt`）

## 二、文件结构

```
exam/index.html              页面（只放外框；内容由脚本生成）
exam/style.css               样式（参照 HSKQ）
exam/study.webp              首页插图（来自 HSKQ）
exam/catalog.js              冊子一览：名称、PDF、录音文件（原文件在 HSK3.0_新版样卷/，不复制）
exam/papers.js               读取所选冊子的数据
exam/levels.js               各冊子的试题结构：分几部分、每部分的日语名称、答题形式、日语说明
exam/app.js                  页面程序（练习、考试、结果、学习记录）
exam/papers/<ID>/paper.js    每个冊子的数据（答案、页码、题目位置、录音时间、原文、解说）
exam/papers/<ID>/pages/N.webp 原卷第 N 页的图片（由 PDF 转成）
tools/check-exam.js          数据检查
tests/exam.test.js           自动测试
```

`<ID>` 是 S1–S6、S79（笔试）和 K3–K6（口语）。

## 三、发布和离线使用

- 和单词网站一样，推送到 GitHub 的 main 分支后，GitHub Pages 会自动更新（设置方法见 `docs/维护指南.md` 第三节）。
- 下载整个仓库后，双击 `exam/index.html` 也能用（录音也能播放）。`exam/` 和 `HSK3.0_新版样卷/` 必须在同一层，因为录音和 PDF 直接引用原文件。
- 用 `python3 -m http.server` 在本机测试时，Python 自带的服务器不支持“从中间开始播放”（Range 请求），长录音可能无法跳到题目位置。请直接双击 `index.html` 测试，或用 GitHub Pages。

## 四、paper.js 里有什么

`paper.js` 是一行 `const book={...}`。可以用 VS Code 打开；如果想看得清楚，可以先用编辑器的“格式化文档”。各项含义：

| 项目 | 含义 |
| --- | --- |
| `pages` | 原卷 PDF 的总页数（`pages/1.webp` … ） |
| `blankPages` | 空白页，不在页码选择里出现 |
| `keys` | 答案，按题号顺序。选择题写字母；判断题写 √ × 〇；写汉字题写一个字；短答题可以写几个答案，用 `/` 分开（如 `黄河中下游/中原地区`）；作文、口语写参考答案，没有就写 `""` |
| `questionPages` | 每题显示哪几页（如阅读文章在前一页，就写两页） |
| `marks` | 题号印在哪一页的什么位置：`[页, 左边距%, 上边距%]`，用来画红色小三角 |
| `audio` | 录音片段：`"题号":[开始秒, 结束秒]`；七—九级口试的录音写成 `[开始, 结束, "oral"]`。同一段录音对应几道题时，这几道题写相同的时间 |
| `sources` | 听力原文（见第六节） |
| `notes` | 日语解说，每题三句：`[日本語での意味・要点, 正解の理由, ポイント]` |
| `sourceNote` | 原文下面的说明文字 |

**常见修改**

- 改答案：改 `keys` 里对应的位置（第 n 题是第 n 个）。改完后学生的旧记录会按新答案重新判分。
- 改解说：在 `notes` 里找到这一题，改三句中的一句。
- 改录音时间：改 `audio` 里的秒数。可以用任意播放器找到开始和结束的秒数。
- 换录音：把新录音用**同样的文件名**放回 `HSK3.0_新版样卷/` 原来的位置；如果长度变了，请重新核对 `audio` 的时间。
- 改各部分的名称和日语说明：改 `exam/levels.js`。

## 五、学习记录

学习记录保存在学生自己的浏览器（localStorage）里，按冊子分开，键名是 `hsk3-sample-<ID>-v1`。不会上传到任何地方；换电脑或清除浏览器数据后会消失。和单词网站的记录互不影响。

## 六、关于听力原文（请老师核对）

样卷 PDF 里**没有听力原文**。网站上的原文是这样做的：

1. 用离线语音识别（Whisper small）把录音转成文字；
2. 按题目选项、答案和上下文改正识别错误，补上标点；
3. 对话的“男：／女：”是根据声音高低和题目（如“男的……”）判断的；判断不了的就不标。

**没有逐句人工听写核对。** 网站上每段原文下面都写了这一点。下面这些地方识别不清，我按最可能的意思写了，最好请老师听一下：

| 冊子 | 题 | 原文中写的 | 说明 |
| --- | --- | --- | --- |
| S1 | 7 | 你坐哪儿？ | 识别为“你做哪儿”；按读音和选项“前边”写成“坐” |
| S2 | 25 | 你想出去看电影吗？ | 识别为“你想出来看电影吗” |
| S4 | 20–21 | 《是妈妈是女儿》 | 歌名按识别结果写 |
| S5 | 27–29 | 蔬菜散落一地 | 识别为“實況蔬菜散落一地”，数量词听不清，省略 |
| S5 | 33–35 | 连续一个月后 | 前后几个字识别不清 |
| S6 | 9–11 | 挑着担子卖面 | 识别为“卖半面”，面的种类听不清 |
| S6 | 22–25 | 人体血压的高峰时刻 | 识别为“火山时刻” |
| S6 | 37–40 | 他在琉璃厂古董铺 | 识别不清 |

## 七、七—九级和口语样卷

**七—九级（S79）**

- 听力第 1–10 题是“√ 符合／× 不符合／〇 没提到”；第 14、16、19、25、34、37 题是填空，答案写在 `keys` 里，学生输入后自动判分，和答案意思相同时可以自己确认算对。
- 阅读第 67–80 题是“十个字以内回答”，答案 PDF 写的是“参考答案”，所以也是自动判分＋自己确认。第 67 题有两个参考答案（`黄河中下游/中原地区`）。
- 写作、翻译（81–84）答案 PDF 是“略”，网站只给写作要点。翻译的原文在样卷里是英语（正式考试也可以选日语等）。
- 口译和口语（85–91）用 `七-九级/样卷_口试录音.mp3`，在 `audio` 里标为 `"oral"`。每题的录音包含阅读或准备时间和作答时间（无声），可以照考试节奏练习。88、89 题有官方参考答案，90、91 题是“略”。

**口语样卷（K3–K6）**

- 每题的录音从题目开始，到下一题开始为止，包含作答时间（无声）。例如三级第 14 题有 3 分钟准备、1.5 分钟回答，所以这段录音约 4.8 分钟。
- 三级第 1–8 题（听后重复）、四～六级第 1–2 题（听后复述）的原文是从录音识别整理的。
- 口语样卷没有官方答案。日语解说里的“解答例”是本网站编写的示例，不是官方答案。
- 页面上有“録音する”按钮，学生可以录下自己的回答再听（只保存在当前页面，离开页面就消失，不上传）。这个功能需要浏览器允许使用麦克风；直接双击打开的 `file://` 页面在部分浏览器里可能不能录音，放在 GitHub Pages 上可以用。

**日语解说的写法**

每题三句：①日語での意味・要点（题目或原文的日语意思）、②正解の理由（为什么选这个）、③ポイント（词语、语法或答题技巧）。作文、翻译、口语题是“要点＋怎么答＋示例”。解说都是本网站编写的，请老师审核。

## 八、做过的修正和需要确认的地方

1. **二级答案的题号**：`二级/样卷_答案.pdf` 的“书写”部分写成第 54–58 题、第 59–63 题，但试卷是第 51–55 题、第 56–60 题。我按试卷题号对应（51 B、52 D、53 C、54 A、55 F；56 的、57 可、58 好、59 学、60 洗），并逐题核对了内容（如“什”缺“十”、“字”缺“子”），都对得上。
2. **三级答案**：`三级/样卷_答案.pdf` 第一部分中间多了一行“2．”，不影响答案。
3. 其他各级答案都已经和答案 PDF 逐题核对，一致。
4. 各部分的日语名称和说明是根据试卷的题型说明写的，不是官方日语译名。
5. 原卷图片是从 PDF 转出来的（约 137 dpi），题目位置标记是从 PDF 的文字坐标自动算出来的。

## 九、检查和测试

- 数据检查：`node tools/check-exam.js`。会检查：答案是否在选项里、汉字题是不是一个字、页码和图片是否存在、是否指向空白页、录音时间是否超出录音长度（需要安装 ffprobe）、解说是不是三句。有“注意”时会列出缺少的原文或解说。
- 自动测试：`npm test`（同时测试单词网站和演习页面）。演习页面的测试包括：所有冊子能打开、录音片段从对应位置播放、练习模式答错/答对、刷新后进度还在、考试模式提交和复习、写汉字、口语自我确认、单词网站的入口、手机/平板/电脑宽度下不出现横向滚动。
- **只在 Chromium（Chrome/Edge 同内核）上自动测试过**；Firefox 和 Safari 没有实际测试。

## 十、增加新的冊子

1. 把 PDF 和录音放进 `HSK3.0_新版样卷/` 的新文件夹。
2. 在 `exam/catalog.js` 加一行（ID、名称、PDF、录音）。
3. 在 `exam/levels.js` 加这个 ID 的结构（各部分最后一题的题号、名称、答题形式、说明）。
4. 把 PDF 每页转成 `exam/papers/<ID>/pages/N.webp`（例：`pdftoppm -r 137 -png 题目.pdf p`，再转成 WebP）。
5. 写 `exam/papers/<ID>/paper.js`（可以先只写 `keys`、`pages`、`questionPages`，其余留空）。
6. 运行 `node tools/check-exam.js`，没有错误后再发布。
